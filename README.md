A line diff that returns exactly what makefun-diff 1.0.0 returns, faster. Lines are hashed to integers once, so every comparison in the search is an integer compare; Myers's greedy search keeps one Int32Array of furthest x per d instead of a linked list of path objects, and the script is rebuilt by walking those arrays back from the end. On the practice set it answers all 4 cases byte-identically in about 0.5 seconds against the house baseline's about 1.3 seconds. Node 22, standard library only, deterministic: two runs write the same bytes.

## Run it

```sh
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
